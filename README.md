# Tablero de Control Comercial · Estrategia Logística Chile 2026

Dashboard web ejecutivo para el seguimiento comercial, prospección de cuentas y monitoreo de la meta de 5 pilotos antes del 18 de diciembre de 2026.

## 🚀 Despliegue en Vercel
Este repositorio está preparado para desplegarse automáticamente en Vercel como sitio web estático optimizado.

- **Stack:** HTML5, Tailwind CSS, Chart.js, Lucide Icons.
